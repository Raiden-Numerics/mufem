# Contributing

Thanks for your interest in mufem!

mufem is developed by [Raiden Numerics](https://raiden-numerics.com). Its source
code is maintained in a private repository. **This repository is not the
development repository** — it hosts a quick introduction to mufem together with a
collection of validation and example cases, and is not open for external code
contributions.

For this reason we **do not accept pull requests** here.

## How you can help

- 🐛 **Report a bug**, 💡 **request a feature**, or ❓ **ask a question** via
  [Issues](https://github.com/Raiden-Numerics/mufem/issues/new/choose)
- ✉️ **Contact us** at [mufem@raiden-numerics.com](mailto:mufem@raiden-numerics.com)

## A note on the information you share

Issues and discussions in this repository are **public**. Please do not include
confidential, proprietary, or personal data (e.g. internal geometries, meshes,
or datasets). Information you submit may be used to improve mufem.
