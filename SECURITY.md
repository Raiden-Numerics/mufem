# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in mufem, please report it **privately**.
Do **not** open a public issue, as issues in this repository are visible to
everyone.

Instead, email us at
[mufem@raiden-numerics.com](mailto:mufem@raiden-numerics.com) with:

- a description of the issue and its potential impact,
- steps to reproduce, and
- any relevant version and environment details.

We will acknowledge your report, keep you informed of our progress, and
coordinate a fix and disclosure with you.

## Supported versions

mufem is under active development. Security fixes are provided for the latest
released version.
